# PROJETO CRUD

Sistema de Cadastro de Clientes e Contatos desenvolvido em Java Console utilizando matrizes String[][].

## Funcionalidades

- CRUD de Clientes
- CRUD de Contatos
- Relação 1 para muitos
- Ordenação manual por nome
- Relatórios
- Crescimento manual das matrizes

## Tecnologias Utilizadas

- Java
- Scanner
